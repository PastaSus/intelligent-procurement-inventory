## Phase 1: Problem Space

**Original Problem Statement:**

> Small businesses lose money by over-ordering or running out of stock. They often guess their supply needs.

### Research Validation (Web Search):

| Finding                                                       | Source        |
| ------------------------------------------------------------- | ------------- |
| $1.77 trillion lost annually to inventory distortion globally | BoxHero blog  |
| 80% of SMBs suffer from overstocking + insufficient planning  | Netstock 2024 |
| 38% of inventory is excess stock on average                   | Netstock 2024 |
| 63% inventory accuracy in US retail (spreadsheets fail)       | Cleverence    |
| 72% of SMEs have unpredictable supplier lead times            | Creviz        |
| 20-30% annual carrying costs on excess inventory              | GoBolt        |

**Key Finding:** The problem IS real. Validated by industry research.

**Gap Identified:** ⚠️ Problem is AI-generated assumption, NOT validated with real SMEs (user noted: "mostly came from Gemini"). TODO: Add customer discovery/validation before final scope.

## Phase 2: Solution Space

### Your Solution:

| Layer              | What                                                                           |
| ------------------ | ------------------------------------------------------------------------------ |
| **CRUD Dashboard** | Traditional admin panel - create/read/update/delete inventory, vendors, orders |
| **AI Agent**       | Conversational layer on top - fetches data, summarizes, suggests actions       |

### AI Agent Details:

- Interface: Chatbot (user types questions, AI answers)
- Data fetching: Queries PostgreSQL
- Output: Summaries, predictions, suggested actions
- Location: Separate page (/ai-chat)

### Key Decisions:

- AI proactively alerts: "You need to reorder X"
- AI suggests POs (draft), human approves
- NO auto-send to vendors (manual approval)

---

## Phase 3: Technical Space

### Stack: PERN + Tailwind

| Layer | Technology        |
| ----- | ----------------- |
| P     | PostgreSQL        |
| E     | Express.js (Node) |
| R     | React             |
| N     | Node.js           |

### Database Schema:

| Table           | Purpose            | Key Fields                                                      |
| --------------- | ------------------ | --------------------------------------------------------------- |
| products        | SKUs               | id, sku, name, description, category, unit_price, reorder_point |
| inventory       | Stock levels       | id, product_id, warehouse_location, quantity, last_updated      |
| vendors         | Suppliers          | id, name, contact_email, lead_time_days                         |
| purchase_orders | Orders placed      | id, vendor_id, status, order_date, expected_delivery            |
| order_items     | Line items         | id, po_id, product_id, quantity, unit_cost                      |
| sales_history   | For AI forecasting | id, product_id, quantity_sold, sale_date                        |
| users           | Admin login        | id, username, password_hash, role                               |

### AI Implementation:

- **Primary:** Gemini API (free tier)
- **Fallback:** Pure JS regression (simple-statistics)
- **Note:** Ollama as local backup option

### API Structure:

```
/api/products     GET, POST, PUT, DELETE
/api/inventory   GET, POST, PUT
/api/vendors     GET, POST, PUT, DELETE
/api/purchase-orders   GET, POST, PUT, DELETE
/api/ai/query    POST (chat with AI)
/api/ai/predict  POST (get forecasts)
```

### Navigation:

- **Desktop:** Fixed left sidebar at md breakpoint

### Dashboard Widget - Low Stock Alerts:

- Red/yellow color coding
- Progress bar showing stock vs reorder point
- "View All" links to inventory page
- Toast auto-dismisses after 3-5 seconds

## MVP Scope

- Inventory CRUD
- Vendor CRUD
- PO Draft creation (with AI help)
- Human approves and sends manually (external)
- AI Chat with predictions (Gemini)
- Low stock alerts

### NOT in MVP:

- Email integration
- Vendor API connections
- Auto-send functionality
- RFQs
- Multiple warehouses
- Advanced reporting
