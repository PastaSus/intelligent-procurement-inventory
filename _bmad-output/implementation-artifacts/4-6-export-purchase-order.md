## Dev Agent Record

### Implementation Notes

**Server Action (`exportPurchaseOrder`):**
- Validates session (must be logged in)
- Fetches PO with vendor and line items
- Validates PO is not DRAFT
- Generates formatted email text with:
  - PO number, date, status
  - Vendor details (name, contact, email, phone, address)
  - Numbered line items table with quantities, prices, totals
  - Grand total
- Returns `{ success: true, data: { content, poNumber } }`

**UI (`handleExport`):**
- Export button visible for APPROVED and SENT POs (all users)
- Click triggers server action
- Attempts clipboard copy via `navigator.clipboard.writeText()`
- If clipboard fails (permissions), falls back to file download
- Toast notification: success or error message
